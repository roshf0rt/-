# Расписание: iOS-приложение с виджетами

Приложение показывает ваши занятия на сегодня. Виджеты есть для экрана блокировки и домашнего экрана.

Расписание вы вводите сами один раз, а дальше оно повторяется каждую неделю. Официального доступа к расписанию УрФУ у приложения нет.

## Что нужно

- Mac с Xcode 15 или новее.
- iPhone с iOS 17 или новее.
- Бесплатный Apple ID.

## Запуск (один раз)

1. Установите XcodeGen (создаёт проект Xcode из `project.yml`):
   ```
   brew install xcodegen
   ```
2. В Терминале перейдите в папку проекта:
   ```
   xcodegen generate
   open UrfuSchedule.xcodeproj
   ```
3. В Xcode выберите оба таргета (`UrfuSchedule` и `UrfuScheduleWidget`) → **Signing & Capabilities** → **Team** → ваш Apple ID.
4. Если Xcode попросит, разрешите создать App Group `group.ru.urfu.schedule`.
5. Подключите iPhone, выберите его сверху и нажмите ▶.

## Использование

1. Нажмите **+** и добавьте занятие: предмет, аудиторию, день недели и время.
2. Добавьте виджеты:
   - **Домашний экран:** долгое нажатие на пустое место → **+** → «Расписание».
   - **Экран блокировки:** долгое нажатие на экран блокировки → **Настроить** → **Экран блокировки** → добавить виджет.

Виджеты обновляются сами, когда начинается или заканчивается занятие и каждую ночь.

## Структура

```
project.yml      настройки проекта для XcodeGen
App/             приложение: список занятий и добавление
Widget/          виджеты для экрана блокировки и домашнего экрана
Shared/          модели занятий и хранилище в App Group
```
