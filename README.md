# Расписание УрФУ: iOS-приложение с виджетами

Приложение показывает расписание группы и виджеты для экрана блокировки и домашнего экрана.

## Что нужно

- Mac с Xcode 15 или новее.
- iPhone с iOS 17 или новее.
- Бесплатный Apple ID (его хватит, чтобы поставить приложение на свой iPhone).

## Запуск (один раз)

1. Установите XcodeGen. Это инструмент, который создаёт файл проекта Xcode из `project.yml`:
   ```
   brew install xcodegen
   ```
2. Откройте Терминал, перейдите в папку проекта и выполните:
   ```
   xcodegen generate
   open UrfuSchedule.xcodeproj
   ```
3. В Xcode выберите оба таргета (`UrfuSchedule` и `UrfuScheduleWidget`) → **Signing & Capabilities** → поле **Team** → ваш Apple ID.
4. Если Xcode просит, разрешите создать App Group `group.ru.urfu.schedule`.
5. Подключите iPhone, выберите его в верхней панели и нажмите ▶.

## Использование

1. Откройте приложение, введите группу (например, `ИЭФ-412`) и нажмите **Сохранить и обновить**.
2. Добавьте виджеты:
   - **Домашний экран:** долгое нажатие на пустое место → **+** → «Расписание».
   - **Экран блокировки:** долгое нажатие на экран блокировки → **Настроить** → **Экран блокировки** → добавить виджет.

## Что сейчас не настоящее

Сейчас приложение показывает **тестовое** расписание (`Shared/ScheduleRepository.swift`, класс `MockScheduleRepository`). Реальный адрес с расписанием пока не подключён: сайт `urfu.ru` отвечает на автоматические запросы ошибкой 403.

Чтобы подключить настоящие данные, нужен адрес, по которому сайт отдаёт расписание группы:

1. Откройте страницу расписания в Safari на Mac, нажмите **Разработка → Показать Web Inspector** (включается в настройках Safari → Дополнительно).
2. Вкладка **Network**, выберите группу на сайте.
3. Найдите запрос, который возвращает расписание (обычно JSON). Скопируйте его URL и пример ответа.
4. Пришлите эти данные в чат. Персональные данные, если они есть в запросе, можно убрать.

Потом будет создан `RemoteScheduleRepository` с тем же протоколом, и `ScheduleService` начнёт использовать его вместо тестовых данных. Остальной код менять не придётся.

## Известные ограничения

- Виджет не ходит в сеть сам. Данные обновляются, когда вы открываете приложение и нажимаете кнопку. Фоновое обновление можно добавить позже через `BGAppRefreshTask`.
- Виджеты для экрана блокировки появились в iOS 16. Проект требует iOS 17 из-за современного API виджетов.

## Структура

```
project.yml                  настройки проекта для XcodeGen
App/                         приложение (экран ввода группы и список на сегодня)
Widget/                      виджеты (экран блокировки и домашний экран)
Shared/                      общие модели, хранилище и источник данных
```
